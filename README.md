# Pooja & Aman — Wedding Invitation

A premium, floral, animated Indian wedding microsite built as a single `index.html`.

**The couple:** Pooja Mathur & Aman Mathur
**The date:** Wednesday, 25 November 2026
**The venue:** Kayasth Samudaiyak Bhawan, 17 Sector, Jodhpur

## Sections

- Full-screen gatefold invitation cover that auto-opens and reveals the landing
- Hero with hanging marigold-and-bell garland, decorated mandap, mandapa pediment and banana plants
- Pullquote banner with peacock-feather accents and rose-petal blessings
- Letter from the families on paper-styled card
- Our Celebration Path — day-by-day event timeline with per-event colour themes (saffron Vinayak, turmeric Haldi, rose Sangeet, crimson Wedding)
- Save-the-Date with a live countdown to 25 Nov 2026, 9:00 PM IST
- Venue card with Rajasthani jharokha illustration and Google Maps directions
- Interactive sealed envelope with a tap-to-open blessing message to guests
- Closing floral arch with couple signature

## Tech

Vanilla HTML + CSS + a tiny bit of JavaScript. No build step, no dependencies. Just open `index.html` or deploy as a static site.

Hosted assets: Google Fonts (Cormorant Garamond, Inter, Dancing Script, Tiro Devanagari Hindi).

## Deploy

Any static host works — GitHub Pages, Netlify, Vercel, Cloudflare Pages. Point them at the repo root; `index.html` is the entry.
